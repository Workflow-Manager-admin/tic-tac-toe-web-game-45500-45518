# Lightweight React Template for KAVIA - Tic Tac Toe

A modern, responsive implementation of the classic Tic Tac Toe game.

## Features

- Start a new game at any time
- Play against another player or the built-in basic AI
- Responsive, clean, centered interface with dynamic status bar
- Win, draw, loss screens with colorful highlights
- Uses a light theme with modern accent colors
- Game board and controls adjust to mobile and desktop

## Environment Variables

`.env` is present for future extensibility and integration. (Currently empty but referenced in code.)
